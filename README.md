# আবু সাঈদ — Abu Sayed Bangla Keyboard

Privacy-first Bangla keyboard for iPhone, iPad and Mac. No tracking, no ads — nothing you type ever leaves your device.

**Website:** https://asifkibria.com/abusayed/
**Privacy policy:** https://asifkibria.com/abusayed/privacy/
**Support:** https://asifkibria.com/abusayed/support/

## Install on Mac (Apple Silicon)

Download the signed & notarized installer from [Releases](https://github.com/AsifKibria/abusayed-keyboard/releases/latest), or use Homebrew:

```sh
brew tap asifkibria/tap
brew install --cask abu-sayed
```

Then enable it: **System Settings → Keyboard → Text Input → Edit → + → Bangla → আবু সাঈদ**
